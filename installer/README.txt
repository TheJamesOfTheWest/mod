Minecraft x Sons of the Forest
==============================
1. Unzip this folder anywhere.
2. Double-click install.bat. It finds your games, installs what's missing and builds the plugin.
3. Read the "HOW TO PLAY" box it prints at the end.

Updating: replace this folder with the new one and run install.bat again.
If anything fails, send Claude the file build-log.txt (created next to install.bat) and BepInEx\LogOutput.log.
Keys: F7 Minecraft mode, F6 Steve drives, E inventory, F10 test explosion, F11 panic.
